User Feedback Insights Agent

An AI agent that finds the top complaints across 30,000 ChatGPT app reviews, checked against my own labels.

Problem

Reading thousands of app reviews by hand is slow, and star ratings alone don't say why users are unhappy. I built an AI agent to sort reviews into themes, measure its accuracy against my own labels, and find what ChatGPT Android users complain about most.

The build

The agent starts with 196,727 raw reviews and removes empty, duplicate, very short and non-English ones, leaving 30,308. Because 76% of reviews are 5-star, a random sample would contain very few complaints. So the agent takes 500 reviews from each rating group (1–2 stars, 3 stars, 4–5 stars), 1,500 in total. It then adjusts the results so each group counts in proportion to its real size.

Claude Sonnet proposed a list of themes from two separate batches of reviews, and 11 themes appeared in both. I reviewed the list and settled on 12 themes, each with a written definition of what it includes and excludes. Claude Haiku then assigns every review to one or more themes, and Claude Sonnet writes a summary of each theme using real quotes from users.

Python code, not the AI, checks that every quote appears word for word in the original review. The same code calculates every percentage and its confidence range (the range the true figure most likely falls in), so the numbers are exact and repeatable. These checks caught the AI inventing a theme that wasn't on the approved list.

Evals

Before building anything, I set aside 100 reviews and labelled them myself as an answer key. Across 4 runs, the agent's theme labels matched mine with an F1 score of 0.78–0.80 (1.0 means perfect agreement), and it judged sentiment (positive, negative or mixed) correctly 79–83% of the time. I made only one round of prompt fixes, so the agent wasn't tuned just to pass my test. After my first 20 labels, I noticed "missing features" was becoming a catch-all, so I tightened its definition before labelling the rest.

Results

Wrong or outdated answers are the most common complaint, at 31% of 1–3 star reviews. Login problems make up 5% of all reviews but 22% of 1–2 star reviews. Crashes (10% of all reviews, 27% of 1–2 star) and bias or censorship (3%, 12%) show the same pattern: a few issues cause a large share of the lowest ratings. Help with studying and learning is the main reason people like the app. Pricing complaints rose from 13% to 21% between late 2023 and mid-2024, but the confidence ranges overlap, so I reported this as a possible trend, not a confirmed one.

What I learned

The biggest accuracy gain came from writing down the rules I was already using in my head. For example, a review that praises the app while also complaining still counts as praise. Adding that one rule raised praise detection from 68% to 80%. I also learned not to trust a single test run: a drop in accuracy that looked real was just normal variation between runs.
